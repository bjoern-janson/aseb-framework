# Permeability

## Overview

Permeability describes the extent to which an adaptive system remains structurally coupled to reality.

ASEB proposes that long-term evolvability depends not only on the ability to process information, but on maintaining pathways through which reality can continue modifying the system.

Optimization without permeability eventually becomes optimization without correction.

---

# Why permeability matters

Every adaptive system exists behind boundaries.

Those boundaries determine:

- what information can enter
- what structures can change
- what assumptions can be revised
- what futures remain reachable

The question is not whether boundaries exist.

The question is whether those boundaries remain permeable to meaningful correction.

A perfectly sealed system may be internally consistent while becoming progressively detached from reality.

---

# Three forms of permeability

ASEB distinguishes three primary forms.

## Causal Permeability

```
P_C
```

Definition:

> The degree to which external reality can causally modify the system.

Questions:

- Can unexpected events change behavior?
- Can environmental feedback alter internal mechanisms?
- Can errors propagate into structural revision?

High causal permeability:

- experimentation
- sensory feedback
- interaction with reality

Low causal permeability:

- isolated optimization
- fixed environments
- self-reinforcing loops

---

## Epistemic Permeability

```
P_E
```

Definition:

> The degree to which beliefs, models, and predictions remain revisable.

Questions:

- Can assumptions be rejected?
- Can failed predictions update models?
- Can contradictory evidence survive?

High epistemic permeability:

- Bayesian updating
- scientific testing
- falsification

Low epistemic permeability:

- dogma
- confirmation bias
- fixed world models

---

## Ontological Permeability

```
O_C
```

Definition:

> The degree to which the system can revise the categories through which it understands reality.

Questions:

- Can entirely new variables emerge?
- Can representations change?
- Can new conceptual dimensions become meaningful?

Examples:

Language increases ontological permeability.

Mathematics increases ontological permeability.

Programming languages increase ontological permeability.

Ontological change is deeper than updating beliefs.

It changes the space in which beliefs can exist.

---

# The permeability hierarchy

The three permeabilities form a nested hierarchy.

```
Reality
    ↓
Causal feedback
    ↓
Belief revision
    ↓
Representation revision
```

Or:

```
P_C
    ↓
P_E
    ↓
O_C
```

Without causal access, epistemic updating fails.

Without epistemic updating, ontology becomes frozen.

---

# Evolutionary significance

Long-term adaptive systems require all three permeabilities.

A system with:

```
P_C ↑
```

can receive feedback.

A system with:

```
P_E ↑
```

can learn from feedback.

A system with:

```
O_C ↑
```

can change what counts as meaningful feedback.

This creates increasingly deep adaptation.

---

# Permeability and evolutionary closure

Evolutionary closure occurs when permeability decreases despite increasing capability.

Example trajectory:

```
Capability ↑

P_C ↓

P_E ↓

O_C ↓
```

The system becomes increasingly effective within an increasingly fixed conceptual world.

ASEB predicts that such systems eventually experience diminishing adaptive potential.

---

# Permeability and optimization

Optimization often reduces uncertainty.

This is valuable.

However, optimization that permanently removes opportunities for correction reduces permeability.

The distinction is:

Healthy optimization:

```
performance ↑

correction remains possible
```

Closed optimization:

```
performance ↑

correction disappears
```

ASEB argues that sustainable evolution requires the former.

---

# Measuring permeability

Permeability is not intended as a single scalar.

Instead, it represents a family of measurable properties.

Possible empirical indicators include:

## Causal Permeability

- response to environmental perturbations
- adaptability under distribution shift
- intervention sensitivity

## Epistemic Permeability

- model revision after failed prediction
- resistance to confirmation bias
- belief update efficiency

## Ontological Permeability

- emergence of new representations
- creation of new latent variables
- structural revision of internal models

Future work will formalize these measurements.

# Relationship to ASEB

Permeability provides the structural conditions that make continued evolution possible.

High capability alone is insufficient.

The system must remain open to:

- correction
- revision
- restructuring

ASEB therefore treats permeability as a prerequisite for evolvability.

Compressed:

```
Permeability

↓

Correction

↓

Adaptation

↓

Structural evolution

↓

Continued evolvability
```

---

# Summary

ASEB proposes that adaptive systems remain evolvable only when they preserve pathways through which reality can continue reshaping them.

Three properties characterize this openness:

- causal permeability
- epistemic permeability
- ontological permeability

These are not optimization objectives.

They are structural conditions that prevent adaptive systems from becoming evolutionarily closed.
