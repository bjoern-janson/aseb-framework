# Representation Boundaries

## Overview

ASEB proposes that the deepest limits of adaptive systems are not only computational.

They are representational.

A system cannot optimize, predict, or adapt over distinctions that it cannot represent.

The first evolutionary constraint is therefore:

> What differences can become meaningful to the system?

---

# The representation boundary

Every adaptive system operates inside a representational boundary.

This boundary determines:

- what distinctions are visible
- what patterns can be detected
- what variables can be optimized
- what transformations can be imagined

A system does not access reality directly.

It accesses a representation of reality.


reality

↓

representation

↓

decision space

↓

action

↓

feedback



The quality of adaptation depends on the relationship between reality and representation.

---

# Distinction precedes optimization

Optimization assumes that relevant differences already exist.

For example:

x₁ > x₂

requires that the system can first distinguish:

x₁ ≠ x₂

Before a system can improve over a variable, that variable must become representable.

Therefore:

distinction

↓

representation

↓

optimization

↓

adaptation

Representation is not a passive storage layer.

It defines the space in which optimization can occur.

---

# Reachable representational dimensionality

ASEB introduces:

D_R

as:

> reachable representational dimensionality

This describes the number and structure of meaningful distinctions available to an adaptive system.

However, raw representational expansion is insufficient.

A system may generate many distinctions that have no effect on prediction, action, or adaptation.

Therefore ASEB uses:

D_R*

adaptive representational dimensionality.

---

# Adaptive representational dimensionality

D_R*

D_R × C_R

where:

D_R

=
reachable distinctions

and:

C_R

=
causal coupling of those distinctions

A distinction becomes evolutionarily meaningful when it can enter the adaptive loop.

A useful distinction can change:

- perception
- prediction
- action
- learning
- future representations

A distinction without causal coupling is only information.

---

# Representation expansion vs information accumulation

More information does not necessarily create more evolutionary capacity.

A system can accumulate:

I ↑

while:

D_R* ≈ constant

because the information remains inside the same conceptual structure.

Examples:

## Encyclopedia

Adds more facts.

information ↑

but may not create new transformation possibilities.

---

## Mathematics

Creates new abstractions.

Creates new abstractions.

D_R* ↑

because entirely new relationships become representable.

---

## Programming

Creates new computational structures.

D_R* ↑

because new classes of transformations become possible.

---

# Representation boundaries and intelligence

Two systems may have equal:

- compute
- memory
- data

but different adaptive potential.

The difference may be:

what distinctions they can express

A system with a richer representation can search a larger space.

A system with a restricted representation may optimize perfectly inside a smaller world.

---

# Representation collapse

A major ASEB failure mode is:

capability ↑

while

D_R* ↓

The system becomes increasingly effective while losing access to new conceptual dimensions.

This produces:

optimization without expansion

The system can improve existing solutions but cannot generate fundamentally different ones.

---

# Historical examples of representation expansion

## Language

Language created a shared symbolic representation layer.

It allowed:

- external memory
- abstraction
- communication
- cumulative improvement

The important transition was:

individual cognition

↓

collective symbolic cognition

---

## Mathematics

Mathematics expanded the representational universe.

It created access to:

- abstract structures
- formal relationships
- general transformations

The contribution was not only solving problems.

It was creating new categories of problems.

---

## Computation

Programming created a representation where transformations themselves could be represented.

The system moved from:

executing instructions

to:

creating instruction-generating systems

---

# Representation boundaries and phase transitions

ASEB predicts that major adaptive transitions occur when representation boundaries shift.

A phase transition is not merely:

more computation

but:

new dimensions of computation become reachable

The transition:

D_R*(t)

↓

D_R*(t+1)

creates new adaptive landscapes.

---

# Relationship to permeability

Representation expansion requires ontological permeability.

If:

O_C ↓

then:

D_R* ↓

because new categories cannot enter the system.

A closed ontology cannot create new evolutionary dimensions.

---

# Summary

ASEB proposes:

Evolution does not only search spaces.

It changes the spaces that can be searched.

The fundamental question is therefore not:

> How efficiently can a system optimize?

but:

> What new distinctions can the system make available for future optimization?

Compressed:

information

↓

representation

↓

meaningful distinctions

↓

adaptive transformation

↓

evolution

The deepest evolutionary transitions occur when systems expand the representational boundaries that define their possible futures.
